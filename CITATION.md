# Cite Memory Prism

The framework has two DOI forms:

- **Concept DOI:** https://doi.org/10.5281/zenodo.19287268 — use this for general reference to Memory Prism across versions. It resolves to the latest version.
- **Version 1.0 DOI:** https://doi.org/10.5281/zenodo.19287269 — use this when citing the specific framework version published in March 2026.

The GitHub repository is a working companion containing the framework PDF, checklist, documentation, and portable AI skill.

- **Framework PDF in this repository:** [MemoryPrism-Framework.pdf](MemoryPrism-Framework.pdf)
- **Official framework page:** https://www.memoryprism.com/framework
- **Official source / essays index:** https://www.memoryprism.com/essays
- **Repository:** https://github.com/memoryprismv1/memoryprism

For citations requiring creator, title, version, publication date, or record metadata, consult the relevant DOI landing page directly and use its authoritative metadata. Do not infer missing bibliographic fields from this repository.
