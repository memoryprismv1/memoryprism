# Starter Kit Checklist

This page points to the canonical version of the checklist rather than maintaining a second, abbreviated copy that could drift.

**[Open Memory Prism Starter Kit — Checklist v1.0](../starter-kit/Memory-Prism-Starter-Kit-Checklist-v1.0.md)**

The canonical checklist is the source of truth for the six entry questions, the three persistence sub-questions, the seven optional lenses, and the AI operating rules.

## Use it lightly

The checklist is a starter kit, not an exhaustive audit or wiki generator. Skip anything that adds no value. One or two optional lenses are a default, not a quota. The aim is to find a productive next question and then follow the domain-specific route.

For assistant behaviour and portability, see the [platform-neutral skill](../skill/README.md).
