# The Framework

The repository's foundational artifact is [MemoryPrism-Framework.pdf](../MemoryPrism-Framework.pdf).

The PDF defines the Memory Prism framework. The companion checklist and skill help apply it; they do not replace or silently redefine it.

## How to read this repository

- **Framework PDF:** the foundational source.
- **Seven supporting essays:** the specified supporting reading for deriving the starter kit.
- **Starter Kit checklist:** the lightweight entry point for unfamiliar topics.
- **AI skill:** operating instructions for assistants using the checklist.
- **Documentation:** orientation and usage guidance.

## Source boundary

The starter kit uses the core framework and exactly these seven essays:

- Boards
- Audits
- Identity
- Flow Under Constraint
- Working Lines
- No Sacred States
- Accumulation Patterns

Other Memory Prism essays may be useful applications or explorations, but they are not required sources for the starter kit.

## Interpretation rule

Examples demonstrate ideas; they do not automatically become definitions. A correspondence between two domains is a prompt to investigate, not proof that the same mechanism operates in both.

When the PDF or a supporting essay does not establish a claim, say so. Do not fill gaps by importing assumptions from general systems theory and presenting them as Memory Prism doctrine.
