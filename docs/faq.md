# FAQ

## Is Memory Prism an exhaustive analysis protocol?
No. The starter kit is an entry point into inquiry. It helps find a useful initial route and stops once a productive next question appears.

## Must every question be answered?
No. Skip anything that adds no explanatory value. The questions are prompts, not mandatory stages.

## Must every topic use all seven lenses?
No. The lenses are optional. One or two are a default starting point; more are justified only when they materially improve the explanation or next step.

## Is a board just physical geometry?
Not necessarily. The relevant conditions can include physical constraints, resources, learned conventions, institutional rules, or nested local conditions. State the actual mechanisms clearly; don't let the word “board” become a vague metaphor.

## Does every system audit or correct itself?
No. Some systems simply change state when physical thresholds are crossed. Talk about detection, interpretation, correction, or governance only when the mechanism supports it.

## What is the difference between a pile check and identity?
A pile check asks whether components form a connected structure or are merely nearby. Identity asks what counts as the same entity or group over time and how membership is maintained. Many questions need the first and not the second.

## Should an AI show its full Memory Prism analysis?
Usually not. It should surface only the observations that help the user, research what needs researching, and follow the next useful question. The framework is there to improve the inquiry, not to make every answer sound alike.

## What happens when the checklist reaches an unresolved question?
Move into domain-specific research, comparison, or testing. Keep alternatives open until evidence distinguishes them. The checklist is not itself the answer.

## What is the authoritative source?
The [Memory Prism Framework PDF](../MemoryPrism-Framework.pdf) is the framework artifact in this repository. The starter kit is a companion tool derived from the framework and the seven named essays.
