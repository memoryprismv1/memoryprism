## Publish

1. Open the repository's **Wiki** tab in GitHub.
2. If no Wiki exists yet, click **Create the first page**.
3. Copy the contents of Home.md into the Home page and save it.
4. Create each remaining page with the title shown above, paste the matching file contents, and save.
5. Click through every Wiki link after publishing.

The GitHub Wiki store is separate from the main repository. These source files keep the pages reviewable and version-controlled even when the published Wiki pages are edited independently.
