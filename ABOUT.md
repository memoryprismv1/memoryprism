# About Memory Prism

Memory Prism is a structural framework for examining how systems form, persist, change, and fail under constraint. Its central vocabulary includes memory, constraints, editors, and boards. The framework aims to make structural patterns easier to notice across domains; it is not a predictive oracle or a replacement for disciplinary expertise.

## Origin and authorship

The project's public [About page](https://www.memoryprism.com/about) describes its origin in extended, adversarial questioning with AI. AI-assisted iteration and documentation are part of the project's stated working method; direction, rejection, and structural decisions remain human-led.

This GitHub repository had a more practical origin. In late March 2026, Claude introduced the creator to Zenodo; the repository was then created as a simple place to keep PDF versions, rather than compare binaries. Its first commit, on 28 March 2026, explicitly described that purpose. It began as a home for the Framework PDF, not as a software project. The repository is now being expanded with companion documentation, the Memory Prism Starter Kit checklist, and a platform-neutral AI skill.

## What belongs here

- **Framework PDF:** the foundational published artifact.
- **Starter Kit:** a selective checklist for entering unfamiliar topics.
- **AI skill:** instructions for assistants applying the Starter Kit without forcing every lens.
- **Documentation:** orientation and reference pages.
- **Wiki sources:** Markdown pages prepared for GitHub's separate Wiki feature.

The Starter Kit's source boundary is the Framework and exactly seven supporting essays: Boards, Audits, Identity, Flow Under Constraint, Working Lines, No Sacred States, and Accumulation Patterns.
